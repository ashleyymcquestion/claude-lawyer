# Founder bios

Each founder answers the questions below (bullet points are fine). Then send
the answers to Claude and it will write three versions of each bio:
- **Short (1 sentence):** for social bios and grant forms with tight limits
- **Medium (2-3 sentences):** for the media kit and most grant applications
- **Long (1 paragraph):** for the website and longer applications

Only real facts. If something is small (like 300 followers), it still counts.
Judges trust specifics.
